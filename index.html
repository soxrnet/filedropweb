FileDrop

v2.3.0
24 Сентября 2026 Стабильная версия
Windows Android Web

FileDrop — передача файлов между ПК и Android по Wi-Fi. Без проводов и интернета. Подключи оба устройства к одной сети, отсканируй QR-код — и отправляй файлы в любую сторону. Ключевые возможности: • Отправка и приём файлов • Подключение по QR-коду • Выбор папки сохранения • Русский и английский интерфейс • Светлая и тёмная тема • Windows + Linux Просто. Быстро. Безопасно.
